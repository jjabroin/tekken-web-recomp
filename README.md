# 🥊 TEKKEN 3 • Web Recomp

> **Borderless Fullscreen 60FPS WebAssembly Runtime for Tekken 3**

브라우저 창 전체를 채우는 몰입형 무테 전체화면 웹 런타임입니다.  
저작권 보호를 위해 독점 게임 롬 및 바이너리는 저장소에 포함되지 않으며, 사용자 소장 롬을 브라우저 로컬 메모리에서 즉시 WebAssembly로 렌더링합니다.

---

## ⚡ 특징
- **Borderless Fullscreen**: 창틀, 에뮬레이터 UI 없이 브라우저 100% 전체화면 렌더링
- **Zero-Server Processing**: 사용자의 롬 파일은 서버로 업로드되지 않고 브라우저 내에서만 100% 로컬 처리
- **60FPS WebAssembly Hardware Acceleration**: 원작 프레임 데이터 및 3D 그래픽 완벽 구동
- **Drag & Drop**: 화면 아무 곳이나 `.bin` / `.iso` 파일을 드래그하면 즉시 게임 시작
